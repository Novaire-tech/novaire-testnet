## What this means in practice

- The contracts have been reviewed for the specific classes of bugs listed in the [Threat Model](/security/threat-model), and every fund-moving call requires `require_auth()`.
- The review that found and tracked SEC-01 through SEC-14 was **not** performed by a licensed, independent security firm.
- The protocol's core exchange rate depends entirely on an external Blend Capital pool's honesty, bounded only by a rate-of-change limiter — this has never been tested against a live Blend pool, only `MockBlendPool`.
- Admin keys are single-signature across every contract. A compromised admin key is a real, currently-unmitigated risk (pause, epoch misconfiguration, and — pre-SEC-06 — instant PT/YT authority reassignment, now two-step).
