## Severity scale (shared by both documents)

- **Critical** — direct, unconditional loss or freezing of user funds, or minting/redeeming outside protocol rules.
- **High** — fund loss achievable under plausible conditions, or breaks a core invariant.
- **Medium** — fund loss only under narrow/unlikely conditions.
- **Low** — fails safe, narrow theoretical exposure, or defense-in-depth gap.
- **Informational** — code quality, documentation, or centralization observation with no direct exploit path.
