| Variable | Used by | Purpose |
| --- | --- | --- |
| `NETWORK` | deploy scripts | `testnet` (default) or `mainnet` |
| `RPC_URL` | deploy scripts | Soroban RPC endpoint; defaults based on `NETWORK` |
| `NETWORK_PASSPHRASE` | deploy scripts | Overrides network passphrase; defaults based on `NETWORK` |
| `ADMIN_SECRET` | deploy/bootstrap scripts | Secret key used to build/upload/deploy/initialize contracts |
| `KEEPER_SECRET` | deploy scripts | Secret key registered as the protocol keeper |
| `BOOTSTRAP_AMOUNT` | `bootstrap_liquidity.ts` | Amount used to seed initial vault/marketplace liquidity |
| `SKIP_BOOTSTRAP` | `deploy.ts` | If set, skips the liquidity bootstrap step |
| `BLEND_POOL` | `deploy.ts`, `deploy_xlm_epoch.ts` | Configured Blend Capital pool address for the new epoch — see [Verification](/deployment/verification) |
| `MATURITY_LEDGERS` | `deploy_xlm_epoch.ts` | Overrides the default ≈30-day testnet epoch length |
| `NEXT_PUBLIC_RPC_URL` | `apps/web` | Soroban RPC endpoint the browser client talks to |
| `NEXT_PUBLIC_NETWORK` | `apps/web` | Network label surfaced to the client |
| `NEXT_PUBLIC_NETWORK_PASSPHRASE` | `apps/web` | Passphrase for client-side transaction building |
| `DATABASE_URL` | Prisma, `apps/web`, `apps/indexer` | Postgres connection string |
| `DATABASE_URL_UNPOOLED` | Prisma migrations | Unpooled Postgres connection string |

<Warning>
  `ADMIN_SECRET` and `KEEPER_SECRET` are raw Stellar secret keys. Never commit `.env` or reuse a funded mainnet key for testnet development.
</Warning>

## Contract-level configuration (set at deploy time, not via env)

| Parameter | Where it's set |
| --- | --- |
| `maturity_ledger` | Computed at deploy time from `MATURITY_LEDGERS` or a hardcoded default |
| `underlying_token` | Native XLM SAC unless already configured |
| `grace_period_ledgers` | Hardcoded `1000` in deploy scripts |
| `blend_pool` | `BLEND_POOL` env var, passed into `factory.deploy_epoch()` |

See [Deployment → Configuration](/deployment/configuration) for how these compose into a full epoch deployment.
