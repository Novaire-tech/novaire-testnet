# pt_token bindings

Generated TS client for the sidereal-tech/contracts-derived `pt_token` contract.
Regenerated by `contracts/scripts/deploy-testnet-resilient.sh` (via
`stellar contract bindings typescript`) as the last step of `npm run
deploy`. The src/ this package had for the old contract set was removed —
run a deploy to repopulate it against the new contract's ABI.
